# Release Procedure

Releases are created through the GitHub Release UI. Creating a release publishes a
Git tag and auto-generated release notes.

## Creating a Release

1. Ensure all intended changes are merged into `main`.
2. Go to the repository's **Releases** page and click **Draft a new release**.
3. In **Select tag**, type the new version (e.g. `v0.2.2`) and select
   **Create new tag**.
4. Set the **Release title** to the same value as the tag name (e.g. `v0.2.2`).
5. Click **Generate release notes** to populate the auto-generated notes.
6. Click **Publish release**.
